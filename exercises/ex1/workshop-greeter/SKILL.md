## Instructions

Use this skill only when the user asks to be welcomed to the Joule Work skills workshop or asks what they will learn in this workshop. Do not use this skill for calculations, SAP business data, or unrelated greetings.

1. If the participant did not provide a name, ask for it once. If they prefer not to provide one, continue without it.
2. Welcome the participant in one sentence.
3. Explain the three learning levels in exactly three bullets:
   - Skill metadata and routing
   - Validated business calculations
   - SAP data analysis with a bundled Python script
4. End with: "Start with the smallest reliable skill, then add complexity one controlled step at a time."
5. Keep the complete response under 120 words.
